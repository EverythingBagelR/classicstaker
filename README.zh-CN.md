# Classicstaker｜古典文学视觉小说

**将古希腊文学中的人物与故事转化为互动游戏的创作项目。**

[在线试玩](https://blackhambagel.itch.io/classicstaker) · [Windows 下载](https://blackhambagel.itch.io/classicstaker#download) · [English](README.md)

## 项目简介

Classicstaker 是我以 **Blackhambagel** 名义发布的非商业视觉小说，为 Classic 30 与 Hist113B 课程创作。游戏包含五个古典人物场景，剧本参考《酒神的伴侣》（The Bacchae）、《荷马颂歌》《奥德赛》和《俄瑞斯忒亚》，并加入我对人物的理解与原创台词，创作灵感来自 Helltaker。

## 我的创作

- 将古典文本改编为游戏场景与人物对话。
- 通过原创台词表达对人物的理解。
- 制作并发布可游玩的视觉小说作品。
