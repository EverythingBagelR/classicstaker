## About the game

Classicstaker is a non-commercial visual novel published under my creator name, **Blackhambagel**. Created for Classic 30 and Hist113B coursework, it reinterprets characters from classical literature across five scenes, combining literary adaptation with original dialogue.

The scripts draw on *The Bacchae*, *Homeric Hymns*, *The Odyssey*, and *The Oresteia*. The project takes inspiration from *Helltaker*.

## My creative work

- Adapted classical texts into scenes and character dialogue.
- Added original lines expressing my interpretation of the characters.
- Created and published the visual novel as a playable project.

**Creator:** Ruijia Chen / [Blackhambagel](https://blackhambagel.itch.io)

## Play

Open the [itch.io page](https://blackhambagel.itch.io/classicstaker) and select **Run game** to play online. For offline play, download the Windows archive from that page, extract it, and launch the game. The creator's page recommends the downloadable version for a more stable experience.
